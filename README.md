# Monografie AI

**De la conversatia cu AI la sisteme agentice verificabile**

Acest repository contine:

- editia stabila a monografiei in Markdown;
- editia PDF;
- documentatia web impartita pe capitole in `wiki/`;
- materiale suplimentare in `docs/`.

## Citeste online

Dupa activarea GitHub Pages, documentatia va fi disponibila la:

https://chrsdme.github.io/Monografie_AI/

## Contributii

Oricine poate propune modificari prin fork + Pull Request. Nu este nevoie de acces direct la repository.

Vezi [CONTRIBUTING.md](CONTRIBUTING.md).

## Structura

- `Monografie_AI_De_la_Chat_la_Sisteme_Agentice.md` - editia completa Markdown
- `Monografie_AI_De_la_Chat_la_Sisteme_Agentice.pdf` - snapshot PDF
- `wiki/` - sursa documentatiei web
- `docs/` - materiale suplimentare / atasamente
- `resurse/` - colectie de resurse si tool-uri
- `experimente/` - experimente, configurari si rezultate
- `fb_ai_romania/` - materiale asociate comunitatii Facebook AI Romania
- `mkdocs.yml` - configuratia site-ului
