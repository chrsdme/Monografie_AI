# Cum contribui

Documentatia este publica, dar continutul oficial ramane controlat prin Pull Request-uri.

## Varianta recomandata

Nu este nevoie sa primesti acces de scriere la repository.

1. Deschide pagina pe care vrei sa o modifici.
2. Apasa **Edit this page**.
3. GitHub iti va crea automat un fork daca nu ai drepturi de scriere.
4. Fa modificarea.
5. Deschide un Pull Request catre `main`.
6. Modificarea intra in documentatia oficiala numai dupa review si merge.

## Ce contributii sunt binevenite

- corecturi tehnice sau de exprimare;
- explicatii mai clare;
- exemple practice;
- studii de caz;
- diagrame;
- referinte si documentatie oficiala;
- rezultate experimentale reproductibile;
- completari ale glosarului.

## Reguli

- afirmatiile tehnice importante trebuie sustinute de surse cand este posibil;
- continutul comercial sau promotional nu este tratat ca dovada;
- exemplele si opiniile trebuie marcate ca atare;
- continutul generat cu AI trebuie verificat inainte de trimitere;
- nu copia integral materiale protejate de drepturi de autor;
- pastreaza stilul general al documentatiei: clar, tehnic atunci cand este nevoie si inteligibil pentru incepatori.

Daca nu vrei sa lucrezi cu Git, poti deschide un GitHub Issue si descrie modificarea propusa.
