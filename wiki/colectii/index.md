# Colectii si contributii comunitare

Pe langa monografia propriu-zisa, proiectul are trei zone care pot creste independent si pot alimenta ulterior documentatia principala.

| Sectiune | Rol |
| --- | --- |
| [Resurse si tool-uri](resurse.md) | Linkuri, documentatie, framework-uri, tool-uri si materiale utile. |
| [Experimente](experimente.md) | Teste, configurari, rezultate si materiale reproductibile. |
| [Material Facebook - AI Romania](fb-ai-romania.md) | Idei, discutii si materiale dezvoltate pornind din comunitatea AI Romania. |

Fisierele efective sunt pastrate in directoare dedicate din repository. Paginile de aici functioneaza ca puncte de intrare si index pentru varianta web.

Contributiile se fac prin Pull Request, iar continutul oficial este integrat numai dupa review.
