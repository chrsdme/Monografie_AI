# Experimente

Zona pentru experimente practice, configurari, rezultate, observatii, metodologii si detalii de reproducere.

## Structura recomandata pentru un experiment

- scopul si ipoteza;
- data si versiunea experimentului;
- modelele, tool-urile si versiunile;
- configuratia si resursele folosite;
- datele de intrare;
- pasii de executie;
- criteriile de evaluare;
- rezultatele;
- limitarile si erorile observate;
- concluziile;
- fisierele sau logurile necesare pentru reproducere.

Scopul este ca un rezultat sa poata fi inteles, verificat si, pe cat posibil, reprodus de altcineva.
