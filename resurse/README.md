# Resurse

Colectie de resurse, documentatie, linkuri si tool-uri utile pentru AI, automatizare, agenti, orchestrare, evaluare si domeniile conexe.

## Ce poate intra aici

- documentatie oficiala;
- articole tehnice si lucrari;
- framework-uri si librarii;
- tool-uri;
- benchmark-uri si seturi de evaluare;
- proiecte open-source;
- cursuri si materiale educationale;
- alte resurse care merita pastrate si explicate.

Pentru continut nou, foloseste un fisier Markdown descriptiv sau adauga materialul intr-un subfolder relevant. Contributiile se fac prin Pull Request.
