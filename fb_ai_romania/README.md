# Material Facebook - AI Romania

Colectie de materiale, discutii, exemple si documente asociate comunitatii Facebook **AI Romania**.

Grup: https://www.facebook.com/groups/1541205557658991

## Ce poate intra aici

- materiale publicate in grup;
- discutii tehnice transformate in note sau documentatie;
- exemple si explicatii;
- intrebari care au generat experimente sau completari ale monografiei;
- documente rezultate din discutii;
- linkuri catre postari relevante, atunci cand acestea pot fi distribuite.

Pentru materiale care contin contributiile altor persoane, pastram contextul necesar, sursa si respectam drepturile de autor si confidentialitatea participantilor.
